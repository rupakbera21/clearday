# Clearday Screenshots Gallery

This folder contains high-resolution browser captures of the Clearday application across all 9 core feature tabs, rendered in both **Dark Mode** (Clearday Sunrise-Teal theme) and **Light Mode** (Clean-Air Mint theme).

## File Manifest

### Dark Mode (Sunrise-Teal Palette)
1. `dark-1-air-snapshot.png`: Air Quality Snapshot, 24h DayStrip, 72h Smog Outlook, Stagnation Panel.
2. `dark-2-today-s-plan.png`: Today's Plan, Low-Exposure Windows, Routine Blocks, Calendar reminder export.
3. `dark-3-community.png`: Community Toolkit, 1-page printable advisories for Schools, Housing, Workplaces.
4. `dark-4-impact-lab.png`: Impact Lab what-if personal exposure ($\mu\text{g/day}$) and $\text{CO}_2\text{e}$ sandbox.
5. `dark-5-home-toolkit.png`: Single-compartment mass balance CADR & DIY box fan calculator, Myth vs Fact cards.
6. `dark-6-alternatives.png`: Sustainable Alternatives Engine ranked by exposure reduction and cost.
7. `dark-7-household.png`: Household composition form and natural-language AI profile parser.
8. `dark-8-ask-clearday.png`: Multi-lingual Q&A with voice read-aloud and emergency symptom interception.
9. `dark-9-privacy-data.png`: Zero-database privacy dashboard, local storage footprint, JSON data export.
10. `live-preview-v3-dark.png`: Full desktop overview (Dark Mode).
